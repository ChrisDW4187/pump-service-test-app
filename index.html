Install, offline use & backups

Open this app over HTTPS while online once. Wait for “Offline ready.” On iPhone/iPad, use Safari → Share → Add to Home Screen → Open as Web App / Add. On Android use Chrome → Install app / Add to Home screen. On desktop use your browser’s install menu.

Drafts and history stay in this browser on this device. They do not synchronize. Private browsing, clearing site data, device loss, or storage eviction can remove them. Export a backup after every test and keep it in your department’s approved storage. Import that file to move records to another device. PDFs are reports, not restorable backups.

Typed signatures record a name only. Follow your department’s review and signature procedures. For temperatures, elevation, engine displacement, and torque, units are not specified in the source workbook; record units in comments.
